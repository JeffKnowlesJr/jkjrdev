PII.link is a full-stack project management tool and time tracker built for professionals who need to stay on top of their work. Authentication keeps data secure, Firebase provides a reliable real-time database, and the timesheet system supports active timers, project tracking, and detailed reporting.

## Features

- User authentication and secure data storage
- Active timers with start/stop/pause controls
- Timesheet management and project tracking
- Clean, focused interface built for daily use
- Modern full-stack architecture with Next.js and Firebase
